## File-level credits

[docs/AUTHORSHIP.json](docs/AUTHORSHIP.json) identifies authors who touched each source file in the reviewed baseline's Git history, normalising aliases to team names. Selected module headers point to this record.

This record preserves historical authorship. Commit counts are not an effort assessment, and a contributor listed for a file is not claimed to have written every line. Design, documentation, testing and management contributions also form part of the project.
